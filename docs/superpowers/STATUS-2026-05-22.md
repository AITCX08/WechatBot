## 已知风险/未决项

1. **wechat-decrypt SSE 路径假设** — 我写的代码默认 `/stream`，实际可能是别的。验证后修改 `wx/receive.py:SSE_PATH`。
2. **事件结构假设** — `_translate_event` 期望 `event_type=="new_message"` 和字段 `msg_id/type/from_user/room_id/content/is_send/timestamp`。实际可能不一样。跑通 sidecar 后看 SSE 输出，对照修改。
3. **decrypted DB 表名假设** — `ContactsBackend` 假设有 `contact` 表（带 `username/nickname/remark/type`）和 `chatroom_member_nickname` 表。Weixin 4.x 真实表名/列名待验证。
4. **UIA 定位器假设** — 已在 `docs/uia-anchors.md` 详记，等你校准。
5. **群 @ 识别** — `WxMsg.is_at()` 当前只检查 `@` 字符出现，不验证 @ 的是哪个 wxid。如果群里别人 @ 了其他成员也会触发 dispatcher。**接入真实流量后可能需要在 dispatcher 那层加更严格的检查**。
6. **`OrderHandler.daily_limit` 默认 50/天**，可以在 config 里改。
7. **`per_user_cooldown_sec` 默认 60s** — 同一用户两次下单间隔。
