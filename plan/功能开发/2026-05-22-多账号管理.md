# 功能开发：多账号管理

> 日期：2026-05-22（架构）+ 2026-05-23（添加账号 UI） ｜ 类型：功能开发 ｜ 状态：✅ 已上线

## 背景

一台机器同时运行多个微信账号，每账号完全独立、互不干扰；账号可在 config.yaml 配置，也可在 Dashboard 运行时动态添加。

## 改了什么

| 文件 | 职责 |
|------|------|
| `dashboard/accounts.py` | `AccountConfig` / `AccountState` / `AccountManager` 生命周期状态机 |
| `dashboard/launcher.py` | `ensure_weixin_running()`：spawn Weixin.exe + UIA 轮询登录窗口 |

生命周期：`STOPPED → STARTING → RUNNING(可 paused) → STOPPING → STOPPED`，失败进 `ERROR`（last_error 记录原因）。
每账号独立持有：WxAdapter / Robot / OrderHandler / 接收队列 / audit log / sidecar 端口 / 解密 DB。

对外接口：
- `GET /api/accounts`、`POST /api/accounts`（pydantic 校验）、`DELETE /api/accounts/{name}`（仅 STOPPED 可删）
- `POST /api/accounts/{name}/start|stop|pause|resume`

配置两种方式：
- config.yaml `weixin.instances` 列表（静态；未配则用 legacy 单字段合成 `default`）
- Dashboard「+ 添加账号」→ 写 `data/runtime_accounts.json`（动态，重启自动恢复，config 优先）

## 为什么这么改

- AccountManager 与 robot/wx 解耦：通过 `BotFactory` 回调构建 bot，本模块只管状态
- start/stop 在后台线程跑（非阻塞），`set_on_status_change` 回调通知上下线
- 登录必须手机扫码（腾讯端到端加密无法模拟）：bot 只负责 spawn Weixin + UIA 轮询登录态
