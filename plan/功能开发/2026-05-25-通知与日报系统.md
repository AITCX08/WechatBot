# 功能开发：通知与日报系统

> 日期：2026-05-25 ｜ 类型：功能开发 ｜ 状态：✅ 已上线（v2.0）

## 背景

bot 主动把重要事件推到对应账号的 filehelper；并按时/按需生成下单统计报告。

## 改了什么

| 文件 | 职责 |
|------|------|
| `router/notifier.py` | 事件分发到 filehelper，cooldown + quiet_hours + 优先级 |
| `router/reporter.py` | 读 audit log 按时窗聚合 + 中文文本渲染 |
| `router/pricing.py` | 平台/课程二级价格查表 |
| `main.py` | 构建共享 Notifier/Reporter/Pricing；定时调度日报 |

### Notifier
- 事件类型：online/offline/order_success/order_dry_run/order_failure/error/sidecar_down
- 限频 key = (account, event_type)，默认 300s；CRITICAL（error/order_failure）绕过
- quiet_hours（如 [0,7]）静默时段内抑制 INFO，CRITICAL 仍推
- 多账号通过 `adapter_lookup(account)` 路由到各自 filehelper

### Reporter
- 时间窗：today / yesterday / Nd
- 聚合：笔数、成功、失败、服务用户数（去重）、累计金额、Top 5 课程
- 金额从 pricing 逐级回退查表（课程精确价 → 平台 default → 全局 default → 0）

### 推送时机
- 定时：默认 22:00（`daily_report_time` 可配），`push_daily_report_to_all` 遍历 RUNNING 账号
- 按需：filehelper 发 /report

## 为什么这么改

- Reporter 读 audit 文件而非内存缓冲：重启不丢历史数据
- 调度器用现有 schedule 库，单线程 30s tick；push 函数提取为可测函数
- 金额不依赖乐学 API（不返回价格），改用本地价格表人工维护
