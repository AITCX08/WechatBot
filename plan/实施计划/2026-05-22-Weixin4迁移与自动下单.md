# 实施计划：Weixin 4.x 迁移与自动下单

> 日期：2026-05-22 ｜ 类型：实施计划 ｜ 状态：✅ 已完成

## 背景

弃用失效的 wcferry，迁移到 Weixin 4.1.7.30：wechat-decrypt sidecar 收消息、uiautomation 发消息；
并在其上做关键词路由 + LLM 下单意图识别 + 自动调乐学 API 下单。

## 分阶段任务（全部完成）

### Phase 0：仓库准备
- [x] wechat-decrypt 加为 git submodule（`wx/sidecar/wechat-decrypt`）
- [x] requirements.txt：删 wcferry，加 uiautomation/pyperclip/pywin32/pytest

### Phase 1：wx/ 包（自底向上，TDD）
- [x] `wx/msg.py` WxMsg 数据类（wcferry.WxMsg shim）
- [x] `wx/contacts.py` ContactsBackend（读解密 SQLite，三向查询 + 缓存）
- [x] `wx/receive.py` ReceiveBackend（sidecar 子进程 + SSE 订阅 → 队列）
- [x] `wx/send.py` SendBackend（UIA 发文/发图/同意好友）
- [x] `wx/adapter.py` WxAdapter facade（组合三 backend，暴露 wcferry 兼容子集）

### Phase 2：robot.py 切换
- [x] configuration.py 加 WEIXIN/LEXUE/ORDER_SAFETY/LLM 配置块
- [x] robot.py import 从 wcferry 换成 wx.WxAdapter；main.py 用 WxAdapter 启动

### Phase 3：路由
- [x] `router/template.py` 关键词/图片/菜单 JSON 匹配
- [x] `router/dispatch.py` 路由链（自消息/好友请求/群过滤/订单/模板/LLM fallback）
- [x] robot.py processMsg 委托给 Dispatcher

### Phase 4：下单
- [x] `router/order_draft.py` OrderDraft 数据类
- [x] `router/order.py` OrderHandler（意图分类 + 字段提取 + 确认状态机 + dry_run + audit）
- [x] prompts/order_intent.md、order_extract.md

## 怎么验证

- [x] 56 个单元测试全绿
- [x] dry_run 模式跑完整下单流程：意图 → 提取 → 确认 → audit log（不真调 API）
- [ ] 真实下单验证（dry_run=false）— **需人工 + 测试乐学账号**

## 关键决策

- sidecar 当子进程而非 import 模块：解耦更新节奏，只依赖 SSE + DB 文件
- send 用 uiautomation 自己写薄封装，不用第三方实验性 UIA 库
- WxMsg 完全模仿 wcferry.WxMsg，让 robot.py 几乎不动
